Compiler Design Conversions Using Python

This project demonstrates the implementation of different phases of a compiler using Python.

Implemented Conversions:

Lexical Analysis

Converts source code into tokens

File: lex.py

Infix to Postfix Conversion

Converts infix expressions into postfix notation

File: infix_to_postfix.py

Postfix to Syntax Tree

Constructs expression tree from postfix expression

File: postfix_to_tree.py

Syntax Tree to Three Address Code (TAC)

Generates intermediate representation

File: tree_to_tac.py

Three Address Code to Quadruples

Converts TAC into quadruple format

File: tac_to_quadruple.py

Quadruples to Target Code

Generates assembly-like target code

File: quadruple_to_target.py
